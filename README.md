This project aims to develop a personalized cost estimation system utilizing machine learning and SQL databases to predict the most accurate construction costs based on critical parameters such as material costs, labour costs, project size, and historical data.
The system will store and manage data using MySQL, ensuring efficient retrieval and processing. 
A Linear Regression model is trained using Scikit-Learn will analyse past project costs and predict future estimates. 
Tkinter-based GUI is implemented to allow real-time user input.
The results will be presented through an interactive interface featuring graphical cost breakdowns and visual representations using Matplotlib.
The system automatically inserts predicted results into a MySQL database, making the solution interactive, scalable, and industry-ready.
